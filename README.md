# Call Back Log

A phone-friendly call tracker for new insurance reps: log each call by voice, see today's callbacks (missed ones turn yellow, then red), and check a contact's open issues and call timeline before you dial.

**Try it:** https://dannymarsh333-gif.github.io/call-back-log/

The live version saves everything in your own browser and starts with fake sample contacts. Please don't enter real client information.

Final project for an AI course. The app is in `app/` (run locally with `node app/server.js`); the problem brief, evidence and scripts are the other files in this folder.
