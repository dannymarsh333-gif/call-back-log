# Final Project: Call-Tracking App for a New Insurance Rep

## Purpose
A phone-friendly web app, run locally, that helps me (a new financial/insurance rep starting January) track cold calls and follow-ups so every callback is informed. This is a real problem I face, NOT a product to sell. Graded: 200 pts app, 100 pts business case.

## Deliverables (one .zip, due Fri Dec 11, 11:59 PM)
1. app/          - the working app (runs locally, works on a phone screen)
2. brief.md      - ONE-page problem brief: who has the problem, what it costs, how it's handled today
3. evidence.md   - survey / user tests with 1-2 charts showing the problem is real and the app helps
4. demo-script.md - script for a 2-minute screen recording (a demo, not a pitch)
(The recording itself goes in the zip too. Check size limit.)
4b. web-page.md  - copy (not code) for a short explainer page; the agent builds the page from it later

Also: solution.md = the app design (source of truth for what to build, and what NOT to build).

## Rules
- Build with agentic/coding tools. Career-related problem only.
- Use FAKE sample contacts only. Never real client data in the app, demo, or zip.
- Only state facts in brief/evidence that come from real data I collected or sources I give. Flag anything unsourced; never invent survey results.
- Keep version 1 small. Version 1 = voice transcript saved as-is. Version 2 = AI auto-sorts into fields.
- Mobile-first layout. Color is never the only signal (add text labels).
- Ask before changing a file I did not mention.
